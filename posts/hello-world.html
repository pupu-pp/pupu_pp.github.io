我的第一篇博客：为什么开始写作

2026-09-13 随笔 约 3 分钟

写作是最便宜的思考工具。很多事情在脑子里想的时候觉得清清楚楚，一旦落到纸面上，就会发现漏洞百出。而这个「发现漏洞」的过程，恰恰就是成长本身。

为什么自己搭博客

因为要记录成长过程

  • 完全掌控：想写什么写什么，不用担心限流和审核；
  • 长期沉淀：域名和仓库都在自己手里，十年后还能打开；
  • 顺便学习：Git、GitHub Pages、HTML/CSS 都能练一遍。

这个博客怎么搭的

没有用任何框架，就是纯 HTML + CSS + JavaScript，托管在 GitHub Pages 上，完全免费。核心步骤只有三步：

  1. 写好静态页面，推送到 GitHub 仓库；
  2. 仓库设置里开启 Pages，选择 main 分支；
  3. 访问 https://用户名.github.io/仓库名，完成。
如果你也想开始写博客，最好的时机是十年前，其次是现在。

接下来写什么

技术笔记、读书摘要、生活碎片，都会写。频率不强求，但尽量每篇都值得写。
