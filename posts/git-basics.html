Git 入门：程序员的第一课

2026-09-10 技术 约 5 分钟

Git 是每个程序员的必备技能。这篇笔记记录我最常用的命令，方便随时翻阅。

最常用的操作流

git status              # 查看当前状态
git add .               # 暂存所有修改
git commit -m "描述"    # 提交到本地仓库
git push origin main    # 推送到 GitHub

把本地项目传到 GitHub

git init
git add .
git commit -m "first commit"
git branch -M main
git remote add origin https://github.com/用户名/仓库名.git
git push -u origin main

常用技巧

  • git log --oneline：一行一条查看提交历史；
  • git checkout -b feature-x：新建并切换分支；
  • git pull：拉取远程最新代码，避免冲突；
  • 提交信息写清楚「做了什么」，三个月后的你会感谢现在的你。
记住：Git 不会弄丢你已经 commit 的代码，所以勤提交、勤推送。
